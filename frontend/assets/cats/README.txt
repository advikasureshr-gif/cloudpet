CAT GIFS
========
Folders:  orange = cat_2_64_64.aseprite | grey = cat_3_64_64.aseprite | black = cat_1_64_64.aseprite
Each folder has 64 GIFs (64x64, transparent, looping, original palette colours) + 8 pose stills (pose_sit_1-4.png, pose_stand_1-4.png).
File names come from the labels on your labelled sheets. Four rows had no label, so I named them from what they show:
  pose_sit, pose_stand (4 separate poses -> stills, not an animation), lie_down_sequence (14 frames), stand_to_lie (3 frames).
Frame timing is my choice (the sheets carry none): walk/run 100ms, jump 110ms, swipes/lick/scratch/meow/yawn/eat 120ms,
tail wag 160ms, on_hind_legs 180ms, stand_to_lie 220ms, hiss 250ms, sleep 600ms.
Open preview.html to browse everything.

EXTRA: go_to_bed.gif (all three cats) = lie down eyes open -> eyes closed -> curled up. 3 frames, 1.4 s, plays ONCE (no loop).
  Use it as the "going to sleep" step, then loop sleep_2_left_front.gif (the curled-up breathing loop; same pose).
NOTE: lie_down_sequence.gif is NOT one animation - it is 14 different sleeping poses in a row (lying front, lying back, curled, stretched).
  Use single frames from it, or the sleep_* GIFs, rather than playing it through.
