CloudPet German Shepherd animation additions

Copy the included folder into your existing CloudPet project, preserving the path:
frontend/assets/dog/

Included GIFs are extracted from the German Shepherd sprite sheet. This ZIP contains only the new dog animation assets; it does not replace or modify your existing HTML/JS files.

Animations: idle, blink, go-to-bed, sleep, walk, run, jump, jump-up, jump-plateau, jump-fall, jump-land, sniff, tracking, bark, slash-attack, death.
